# LabLink – University Laboratory Resource Sharing Platform

## Overview
LabLink is a web-based platform designed to simplify access to specialised laboratory equipment across different university departments.

It provides a centralised marketplace where students can discover available equipment, explore its applications, check availability and request bookings. Laboratory assistants can manage booking requests, approvals, equipment maintenance and resource availability.

## Key Features
- **Equipment Marketplace:** Browse specialised equipment across multiple departments.
- **Equipment Details:** Explore specifications, applications, skills required and laboratory locations.
- **Booking System:** View available time slots and request equipment reservations.
- **Conflict Prevention:** Prevent overlapping reservations for individual physical equipment units.
- **Booking Management:** Lab assistants can approve, reject and manage booking requests.
- **Maintenance Management:** Track equipment maintenance and availability.
- **Project Resource Discovery:** Explore projects and their associated equipment requirements.
- **Student Dashboard:** Track booking requests and reservation history.
